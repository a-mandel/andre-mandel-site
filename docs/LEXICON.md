# ANDRÉ MANDEL · Lexicon

Your house lives in a Living Set, true size sheets you page through like a bound set, with the model open on the Model Cover and the Title Rail always showing where you are.
Every milestone is a dated Issue, and each Issue prints a Blueline for Placer County with a Ribbon that brings anyone straight back to the live drawings.
Behind it, my Drafting Room works from one Job Book, so nothing we decide gets lost. I call it Drawing Live.

Draft 9/30/26. One recommended name per concept, a line in my voice, and a short list of alternates.

## The set

### Living Set
The whole drawing set as a live web page: true 36 x 24 sheets, bound on the left, always current.
_Alternates: Standing Set, Open Set_

### Blueline
The static PDF at true size, pulled from the Living Set the way bluelines were pulled from vellum, for building departments and the record.
_Alternates: Pressing, Plot_

### Cartoon Set
The first pass: every sheet laid out with boxes showing where each view will go, before a line is drawn.
_Alternates: Sheet Map, Layout Set_

### Issue
Each dated release of the set, numbered and logged newest first in the title block, so you can see the house grow.
_Alternates: Edition, Delta_

### Pocket Set
The Living Set on your phone: the drawing fills the screen and the title block folds into a strip at the bottom.
_Alternates: Half Size, Field Set_

### Ribbon
The link and QR code on every Blueline that ties the paper back to the Living Set, like the ribbon marker in a bound book.
_Alternates: Thread, Tether_

## The sheet

### Title Rail
The title block running full height on the right, holding the sheet index, the Issues and the stamp, and taking you to any sheet.
_Alternates: Keel, Masthead_

### Model Cover
The cover sheet with the live 3D model sitting in it, so the first thing you see is the house on its site.
_Alternates: Maquette, Window Sheet_

### Hand Notes
The handwritten notes that write themselves onto the sheet, each with a thin leader to the thing it is about.
_Alternates: Live Ink, Marginalia_

### Corner Lift
The lower corner of the sheet that stirs a little to invite the next page turn.
_Alternates: Thumb, Dog Ear_

## The studio

### Drafting Room
The team of AI drafters working the set together, each at their own board, the way an office used to run a drafting floor.
_Alternates: Bullpen, Atelier_

### Job Book
The one shared file every drafter reads first and writes back to: decisions, rules, data and the brief.
_Alternates: Ledger, Master Book_

### Board
One drafter's lane in the Drafting Room: the plans board, the elevations board, the fire board, the interiors board, the admin board.
_Alternates: Desk, Bench_

## The approach

### Drawing Live
How I work in one breath: I draw your house live, in the open, and issue it on paper when it counts.
_Alternates: Open Drafting, Living Drafting_
